# VectorCP identity

<img src="assets/brand/vectorcp-wordmark.svg" alt="VectorCP" width="340">

VectorCP is pronounced “Vector C P.” Keep the capital V, C and P in prose;
use `vectorcp` for the repository, Python package and machine-readable name.

- Descriptor: **Open-source hosting control.**
- Brand line: **Your hosting. Your control.**
- Workspaces: **Owner**, **Reseller** and **Customer**.
- Maintainer: [SparkX Digital](https://www.sparkxdigital.co.uk/).
- Website: [vectorcp.net](https://vectorcp.net/).

## The mark

The split V combines a grounded chevron with a detached directional tip. The
visible gap is part of the mark. Use the standalone mark for icons and the
wordmark for headers, documentation and project identification. The artwork is
original to VectorCP and included with the project's MIT source.

Source assets in `assets/brand/`:

| Asset | Use |
| --- | --- |
| vectorcp-wordmark.svg | Forest/leaf wordmark on light backgrounds |
| vectorcp-wordmark-light.svg | Light wordmark on dark backgrounds |
| vectorcp-wordmark-mono.svg | Single-colour reproduction |
| vectorcp-mark.svg | Standalone mark on light backgrounds |
| vectorcp-mark-light.svg | Standalone mark on dark backgrounds |
| vectorcp-mark-mono.svg | Single-colour mark |

All files are scalable SVG paths with transparent backgrounds. The rounded app
icon is `vectorcp/static/favicon.svg`. Wordmarks need no font download or
external asset request.

## Colour and spacing

Forest `#183E33` is the primary ink; leaf `#72A36B` distinguishes the directional
tip. Reverse artwork uses mist `#F6F9EE` and lime `#B9DF92`. Use the mono variant
for one-ink reproduction. Keep UI text at accessible contrast; the accent is a
brand colour, not a universal text colour.

Leave at least the width of the V's left stroke around the artwork. Use the
wordmark at 120 CSS pixels or wider; below that use the standalone icon. Keep
icons at 16 CSS pixels or larger. Do not stretch, rotate, add shadows, rearrange
the tip or rebuild the wordmark with a substitute font.

## Product description

VectorCP is a free, open-source hosting control panel for managing websites and
running a hosting business on your own server. It brings owner, reseller and
customer workspaces into one independently written, MIT-licensed product.
The development release has working hosting foundations; consult
[FEATURES.md](FEATURES.md) for actual availability and limits.

Avoid unsupported feature, security, capacity, endorsement or trademark claims.
