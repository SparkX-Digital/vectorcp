# VectorCP

**Open-source hosting control.**

VectorCP is the chosen public name for this independently written, MIT-licensed
hosting control panel. The name is pronounced “Vector C P.” Use the full name
to distinguish the product from other software using the word Vector.

## Identity

- Product name: **VectorCP**. Keep the capital V, C and P in prose.
- Repository and machine-readable project name: `vectorcp`.
- Descriptor: **Open-source hosting control.**
- Brand line: **Your hosting. Your control.**
- One product serves server owners, resellers and customers. Use these role
  names rather than creating a second product identity for administration.
- The original V mark and forest-green palette remain the interface identity.
  The existing mark is original to this project; no competitor assets are used.

The code is licensed under MIT. Do not claim registered trademarks, endorsements,
benchmarks, customer numbers or completed features without evidence.

## Product description

VectorCP is an open-source hosting control panel for server owners, resellers
and customers. Its target is an alternative to cPanel/WHM with BHPanel's
documented feature coverage, implemented independently. The current release is
an early development milestone; consult `FEATURES.md` for implemented and
planned capabilities.

## Release and deployment names

New source releases use `VectorCP-<version>-source.zip`, with an archive root
of `VectorCP-<version>`. Earlier archives retain their historical names.

The current runtime retains legacy `veyra` identifiers to preserve existing
installations. These implementation names do not change the public identity.
See the compatibility note in `README.md` before altering installation paths.

The user-designated public website is `vectorcp.net`, and the intended
development repository is `SparkX-Digital/vectorcp` on GitHub. SparkX Digital
maintains the project. These publication destinations do not change the
installer, application endpoints or update mechanism.
