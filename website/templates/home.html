A few things to know

Before you get started.

Is VectorCP free to use?

Yes. The source is released under the MIT license, with no activation fee. You provide and operate your server. Server hosting, domains and any external services have their own costs.

Which server can I install it on?

The exercised development platform is a dedicated, fresh AlmaLinux 9 x86-64 server. Read the installation guide first. Do not install it over an occupied hosting server or another control panel.

Is it ready for production hosting?

VectorCP is a development preview. Hosting and recovery checks have passed for documented workflows, but broader production acceptance, an independent security audit and complete disaster recovery remain open. Check the feature status and verification notes.

Can hosting companies and agencies use the source?

The MIT license permits commercial use and modification, subject to its license terms. Owner, reseller and customer roles are implemented. Evaluate the current limits on a dedicated test server before offering a service.

How can I help build VectorCP?

Start with the contribution guide, inspect the roadmap and propose a focused change on GitHub. Report security issues through the private reporting process.
